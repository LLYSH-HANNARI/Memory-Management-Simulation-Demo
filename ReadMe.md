
# 存储管理实验演示系统 (Memory Management Simulation)

本系统是一个基于 **C 语言** 实现的操作系统存储管理模拟程序。它通过模拟动态分区分配（Dynamic Partition Allocation）过程，演示了操作系统如何管理内存的分配与回收。

## 1. 项目简介

本项目旨在通过编程模拟，直观地展示动态分区存储管理中的三种核心算法：**首次适应算法 (FF)**、**最佳适应算法 (BF)** 和 **最坏适应算法 (WF)**。程序实现了内存空间的申请（作业分配）以及作业完成后的内存释放（空间回收与合并）。

## 2. 核心算法说明

程序通过对空闲分区链（Subarea List）的不同维护方式来实现不同的分配策略：

| 算法名称 | 缩写 | 核心逻辑 |
| --- | --- | --- |
| **首次适应算法** | FF | 空闲分区按**首地址升序**排列。分配时从链首开始查找，找到第一个满足大小的分区即进行分配。 |
| **最佳适应算法** | BF | 空闲分区按**容量从小到大**排序（`BestFreeSort`）。分配时优先使用能满足要求的最小分区，以保留大分区。 |
| **最坏适应算法** | WF | 空闲分区按**容量从大到小**排序（`WorstFreeSort`）。分配时总是使用最大的分区，使剩下的块不至于太小。 |

## 3. 主要功能模块

### 3.1 内存分配 (`Assign`)

* 支持作业进入内存的动态申请。
* 自动根据选定的算法（FF/BF/WF）在空闲链表中检索合适区域。
* 支持分区的切割：若分区大于作业需求，则分割该分区，剩余部分保留在空闲链中。

### 3.2 内存回收 (`FreeReclaim`)

* 当作业运行结束时，将其占用的内存空间回收到空闲链表中。
* **合并逻辑**：
* **有下邻**：与后方的空闲分区合并。
* **有上邻**：与前方的空闲分区合并。
* **上下均相邻**：三块区域合并为一个连续的大空闲区。
* **无相邻**：作为独立分区按首地址顺序插入链表。



### 3.3 数据结构

* `JCB` (Job Control Block)：存储已分配作业的信息（名称、地址、大小、状态）。
* `SUB` (Subarea)：存储空闲分区的信息（名称、首地址、大小、状态）。

## 4. 文件说明

* `存储管理实验演.c`: 程序的主源代码文件。
* 系统初始状态：预设总内存大小为 **512 KB**，起始地址为 **0**。

## 5. 如何运行

### 环境要求

* 操作系统：Windows (程序中使用了 `system("cls")` 进行清屏，建议在 Windows 环境下运行)。
* 编译器：GCC 或任何支持标准 C 语言的集成开发环境（如 Dev-C++, Code::Blocks, Visual Studio）。

### 编译运行

1. 打开终端或编译器。
2. 输入编译命令：
```bash
gcc 存储管理实验演.c -o MemoryManagement.exe

```


3. 运行生成的程序：
```bash
./MemoryManagement.exe

```



## 6. 使用流程

1. **启动**：进入演示界面，按下任意键开始。
2. **算法选择**：在主菜单中选择要使用的分配策略（1. FF, 2. BF, 3. WF）。
3. **操作演示**：
* 输入 `2` 进行分配：设定作业名称和所需内存大小。
* 输入 `1` 查看空闲表：实时观察内存分布情况。
* 输入 `3` 进行回收：输入要撤出的作业名，观察空闲区的动态合并。


4. **退出**：输入 `0` 返回上级或退出程序。

## 7. 注意事项

* 本程序仅供学习与实验演示使用，不得用于商业用途。
* 在分配作业时，若作业所需空间大于当前最大空闲分区，系统将报错并提示分配失败。
